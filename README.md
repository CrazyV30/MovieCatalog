Щоб запустити в себе даний проєкт потрібно:
1. За допогомою команди git clone з клонувати даний проєкт собі на комп'ютер
2. У Visual Studio відкрити файл із розширенням .slnx з папки backEnd
3. У Visual Studio Code/Webstorm відкрити безпосередньо папку frontEnd
4. У Visual Studio запустити проєкт за допомогою вбудованого запуску
5. У Visual Studio Code/Webstorm відкрити консоль та вписати туди команду npm start
